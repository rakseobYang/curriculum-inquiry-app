# 기말과제 영상 제작 및 현재 상태

## 확인한 과제 기준

[교수님 기말과제 안내 페이지](https://thlim-ai-agent.notion.site/41b1098d25ba8172938df83737a7eebd)에서 다음 조건을 확인했다.

- 트레일러: 30–60초, MP4. 앱을 누가 쓰는지와 무엇이 유용한지를 앞부분에 둔다.
- 과정 영상: 2–3분, MP4. 수정 전후 화면을 나란히 보여 주고, 무엇을 왜 바꿨는지와 AI에게 요청한 내용을 자막으로 담는다.
- 두 영상의 제작 코드는 `video/` 폴더에 둔다. 안내 페이지는 Remotion으로 만들 것을 제시한다.
- 화면 수정 전 캡처를 남겨 영상에 사용한다.

## 현재 보유 자료와 미완료 항목

`render.mjs`와 `verify.mjs`는 Edge를 이용해 정지 캡처와 자막 카드로 WebM 스토리보드 초안을 만든다. 현재 `process.webm` 약 24초, `trailer.webm` 약 9초이며, Remotion 프로젝트·MP4 출력·지정 길이·실제 앱 흐름은 아직 준비되지 않았다. 두 초안은 요구 규격을 충족하는 제출본이 아니다.

- [ ] Remotion 제작 코드로 과정 영상 2–3분과 트레일러 30–60초 구성
- [ ] 과정 영상에 수정 전후 병렬 화면, 변경 이유, 실제 AI 요청을 포함
- [ ] 두 영상 MP4를 렌더링하고 전체 재생 확인
- [ ] 앱 이름, 공개 저장소·배포 주소가 영상·체크리스트와 일치하는지 확인
- [ ] 제출 후 Padlet 글에는 영상 하나, 다른 영상은 댓글에 첨부

교수님 안내는 13주차 녹화 강의에서 자세한 제작법을 다룬다고 언급하지만, 그 강의 영상은 확인하지 않았다. 해상도·음성 조건은 안내 페이지에서 찾지 못해 임의로 요구사항에 추가하지 않는다.

## 현재 초안 재생

저장소 루트에서 `npm ci` 후 `node video/render.mjs`로 초안을 만들고 `node video/verify.mjs`로 WebM 재생·화면 크기·장면 전환을 확인할 수 있다. 이 명령은 과제 제출 규격의 Remotion MP4 산출을 수행하지 않는다.

`video/out/`은 `.gitignore` 대상이다. 최종 제출 전에 MP4 파일을 제출 패키지에 포함하고 별도 재생 확인을 해야 한다. Padlet에 게시하거나 저장소를 공개로 전환하는 작업은 계정·공개 설정 변경이므로 명시적 진행 지시 전에는 수행하지 않는다.
## 구현 전 영상 구성안

아래 시간은 제작 목표이며 아직 렌더링하지 않았다. 과정 영상 150초, 트레일러 45초는 확인된 안내의 길이 범위 안에서 정한 선택이다. 장면에서 가상 자료를 쓰면 화면에 ‘가상 자료 시연’을 표시하고, 실제 서비스에서 검증하지 않은 동작에는 ‘개발 중’ 표시를 넣는다. 누락된 실제 AI 요청 문구를 새로 만들어 과거 요청인 것처럼 쓰지 않는다.

### 과정 영상: 150초

| 시간 | 화면과 전달 내용 | 필요한 증거·준비 상태 |
|---|---|---|
| 0–12초 | 교사가 성취기준부터 탐구·설명·생활 문제 적용까지 연결해야 하는 과제와 앱 목표 | 제목·목표 자막 작성 가능 |
| 12–30초 | 2022 공식 기준과 교과서 내용 참고의 관계. 과학3은 2015 판본임을 표시 | 원자료 대신 직접 만든 구조 그림. 교수 강의를 시청했다는 문구 사용 금지 |
| 30–45초 | 실제 개발 날짜와 주요 변경을 타임라인으로 표시 | 현재 기록·커밋은 두 날짜분. 5일 요건은 실제 날짜 증거 확보 후 편집 |

| 65–85초 | 디자인 변경 2: 입력 단계 구획 개선의 전후 비교와 실제 요청 자막 | 제안 단계. 실제 수정·전후 캡처·요청 기록 확보 필요 |
| 85–105초 | 디자인 변경 3: 근거 범위·판본·권한 상태 가독성 개선의 전후 비교 | 제안 단계. 실제 수정·전후 캡처·요청 기록 확보 필요 |
| 105–130초 | 성취기준·조건 입력→근거→수업안→교사 수정·저장·출력 흐름 | 승인된 자료와 배포본 시연 필요. 가상 화면 사용 시 가상 시연임을 표시 |
| 130–142초 | 모바일·자료 미확보·실패 후 재시도와 확인한 한계 | 실서비스 인수 증거 확보 후 결과 표시. 형식 검사와 교사 내용 검토 구분 |
| 142–150초 | CHECKLIST·저장소·배포 주소 및 남은 개선 | 실제 열리는 주소만 표시. 미배포 URL을 만들지 않음 |

### 트레일러: 45초

| 시간 | 화면과 전달 내용 | 필요한 증거·준비 상태 |
|---|---|---|
| 0–6초 | ‘중학교 과학 교사를 위한 탐구 수업 설계’와 교사의 준비 과제 | 목표 소개 자막 |
| 6–15초 | 성취기준·차시·시간·장비 입력 | 승인된 시연 화면 또는 가상 자료 표시 |

### Remotion 코드 준비 설계

구현이 시작되면 `video/` 안에 독립 패키지 설정, 진입점, 두 영상의 Composition 등록, 장면 컴포넌트, 검토한 공개 가능 이미지, 렌더 절차를 둔다. 현재 이 구조의 코드와 명령은 미작성이다. 기존 Edge WebM 제작 코드를 Remotion 코드로 표기하지 않는다.

제작 설정 제안은 1920×1080, 30fps이며 교수님 필수 사양으로 확정한 값이 아니다. 이 설정을 선택하면 과정 영상 4,500프레임, 트레일러 1,350프레임으로 구성한다. 최종 출력은 MP4로 하고 실제 길이·재생·한글 자막·전후 캡처 가독성을 확인한다. 해상도·음성에 관한 추가 강의 지침이 확인되면 먼저 반영한다.

### 최종 영상 완료 판단

- 두 MP4의 실제 길이가 각각 120–180초, 30–60초이고 처음부터 끝까지 재생된다.
- 실제 수정한 디자인 변경 3건이 CHECKLIST 행·전후 캡처·변경 이유와 일치한다.
- AI 요청 자막은 보관한 실제 요청에 근거하고 미보관 내역은 미보관으로 표시한다. 미보관 표시만으로 강의의 요청 자막 요건을 충족했다고 간주하지 않는다.
- 촬영 화면·자막·오디오에 원자료 페이지, OCR, 미승인 교과서 요약, 비밀키, 학생 식별정보가 포함되지 않는다.
- 사용된 화면의 커밋·캡처 날짜·가상/실서비스 여부를 제작 기록에서 추적할 수 있다.
- 공개 주소가 영상·README·CHECKLIST·제출 글에서 일치하고 비로그인 상태에서 열린다.

현재 보유한 WebM 두 편은 구성 참고 자료이며 위 항목의 완료 증거로 대신하지 않는다.
