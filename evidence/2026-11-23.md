# Cloudflare 및 GitHub Pages 연결 준비

- 기존 `main`과 로컬 변경을 확인했다. 시작 시 3000·8787 포트 리스너는 발견되지 않았다.
- 기존 단위 테스트 4건과 Edge 360px 모의 검증 결과를 확인했다. `node scripts/check-release.mjs`와 `npm.cmd run check:pages` 재실행은 통과했다. 공개 산출물 25개와 공식 성취기준 87건을 확인했다.
- Actions에서 비공개 SQL 없이 빌드할 수 있도록 일반 빌드와 공개 데이터 갱신 명령을 분리했다. Actions에 업로드 전 산출물 검사를 추가했다.
- 실제 GitHub CLI 인증을 확인했다. Pages 설정 조회는 HTTP 404를 반환했다.
- Wrangler `whoami`에서 인증이 필요함을 확인했다. OAuth를 시작하고 사용자에게 직접 승인하도록 안내했다. 실제 모델 요청, Worker 배포 및 GitHub Pages 게시 결과는 미확인이다.

## 무료 구성 전환

- Wrangler OAuth는 승인 코드를 받기 전에 만료됐다.
- OpenAI 키 기반 호출을 Workers AI 바인딩으로 교체했다. 수업안은 IndexedDB에, 사용량 카운터는 SQLite Durable Object에 둔다. Turnstile과 출처·입출력 검증을 유지했다.
- Workers AI 모의 응답을 이용해 API를 검증한다. 실제 추론과 배포는 Cloudflare 계정 인증 이후 확인해야 한다.
